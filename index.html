Tentang Saya

Saya adalah Software Engineer dengan pengalaman lebih dari 4 tahun dalam pengembangan aplikasi dan software, dengan fokus pada Backend Development, Full-Stack Development, Mobile Application, REST API, dan Database.

Selama berkarier, saya terbiasa mengembangkan aplikasi dari proses analisis kebutuhan, perancangan sistem, pengembangan fitur, integrasi API, pengelolaan database, hingga testing dan maintenance.

Saya memiliki pengalaman bekerja dengan berbagai teknologi seperti Java, Spring Boot, Node.js, Python, Flutter, JavaScript, MySQL, Oracle, REST API, Git, dan Docker. Saya juga memiliki perhatian terhadap clean code, struktur project yang baik, keamanan aplikasi, scalability, dan maintainability.

Bagi saya, software engineering bukan hanya tentang menulis kode, tetapi tentang memahami masalah, menemukan solusi yang tepat, dan membangun software yang benar-benar memberikan manfaat bagi pengguna maupun bisnis.

Saat ini saya terus mengembangkan kemampuan di bidang software engineering dan terbuka untuk berkolaborasi dalam membangun produk digital yang reliable, scalable, dan memberikan real business value.
